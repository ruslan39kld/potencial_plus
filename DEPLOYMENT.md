## 📦 Что было сделано

### ✅ Полностью разработанный телеграм-бот с 5 AI-ассистентами:

1. **🎯 Карьерный помощник** - подбор профессий, треков, вакансий
2. **💰 Финансовый консультант** - расчет финансовой подушки безопасности

## 🚀 Как запустить (3 шага)

### 1️⃣ Установите зависимости
```bash
cd hr_career_bot
pip install -r requirements.txt
```

### 2️⃣ Настройте .env
```bash
cp .env.example .env
nano .env  # Добавьте токены
```

Пример .env:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHI...
GIGACHAT_CLIENT_SECRET=ваш_ключ_здесь
```

### 3️⃣ Запустите
```bash
python src/bot.py
```

**Готово!** Бот запущен 🎉

## 🔧 Интеграция с существующими ботами

Этот бот **полностью совместим** с архитектурой EASUZ_BOT:

### Общие компоненты:
✅ `hybrid_search.py` - тот же файл  
✅ `process_knowledge_base.py` - совместимый формат  
✅ База данных - аналогичная структура  

### Можно переиспользовать:
- Векторный индекс из `data/easuz_index/`
- Структурированные Q&A из `structured_qa.json`
- Chunks из `chunks_data.json`

### Как объединить с EASUZ_BOT:
1. Скопируйте индекс: `cp -r easuz_bot/data/easuz_index hr_career_bot/data/vector_index`
2. Скопируйте данные: `cp easuz_bot/data/*.json hr_career_bot/data/knowledge_base/`
3. Запустите бота - он автоматически использует индекс

## 🎯 Адаптация под проект Potencial Plus

### Встроенные знания о проекте:

**Целевая аудитория:**
- Россияне с доходом до 100 000 руб/мес
- Массовые профессии (курьеры, строители, водители, сварщики и т.д.)

**Ключевые принципы:**
1. Вахтовая работа = инструмент формирования капитала
2. Финансовая подушка = основа уверенности
3. Карьерный рост = план + действия + поддержка
4. Международные возможности = вторая фаза развития

**Платформы в меню:**
- Основной сайт: potencial-plus.ru
- Вакансии: tempojob.org
- Международные: russian.works

**Психологические тесты:**
- Тест КОС (коммуникативные способности)
- Тест Томаса (поведение в конфликтах)
- Тест Герчикова (мотивация)

## 📊 База данных (SQLite)

### 4 таблицы:

1. **users** - пользователи (id, username, premium статус)
2. **messages** - история сообщений (вопрос, ответ, время)
3. **usage_limits** - лимиты использования (дата, количество)
4. **completed_tests** - пройденные тесты

### Типичные ошибки:

**GIGACHAT_CLIENT_SECRET not found**
→ Проверьте .env файл

**FileNotFoundError: index not found**
→ Индекс опционален, бот работает без него

**Markdown errors**
→ Автоматически исправляются в `sanitize_markdown()`
